✨ What's New & Upgraded in v1.0.7:
  • 🗣️ Voice Output (Agent Speaks Aloud): Integrated Text-to-Speech enabled by default so the agent talks out loud with fluid speech. Tap the new Speaker icon in the top bar to mute/unmute.
  • 🎙️ Voice Input (Speech-to-Text): Android 11+ package visibility and runtime permission checks for seamless speech recognition.
  • 💬 Real Conversational Dialogue: Natural conversational chat ("can we talk", "how's your day", "i'm bored", "tell me a story", "give me advice", "who created you").
  • ⏰ Live Clock & Date: Real-time live system time and date queries ("what time is it", "what's today's date").
  • 🚫 Zero Errors / Clean Fallbacks: Eliminated JSON parse failure messages and technical exception toasts in favor of natural conversational assistance.
