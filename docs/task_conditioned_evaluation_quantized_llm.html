Abstract

Large Language Models (LLMs) achieve remarkable reasoning capabilities, but their extreme memory footprints present a prohibitive barrier to deployment on resource-constrained consumer edge devices. Post-Training Quantization (PTQ) addresses this memory wall by compressing 16-bit floating-point weights down to 8, 4, or 2 bits, yielding reductions in memory bandwidth demands that are vital for real-time autoregressive generation. However, foundational empirical claims in early quantization literature—most notably that 4-bit quantization causes negligible accuracy loss and that language-modelling perplexity serves as a universally reliable proxy for task performance—predate the standardized adoption of complex multi-step reasoning benchmarks (e.g., GSM8K) and instruction following (e.g., IFEval).

This Major Project presents a rigorous, task-conditioned empirical evaluation of post-training quantized open-source LLMs in the sub-2B parameter regime: Qwen2.5-0.5B-Instruct, Llama-3.2-1B-Instruct, and Pythia-1.4B, extended to edge deployment engines including Google Gemma-2-2B-Instruct. We evaluate models across full-precision FP16 baselines, 8-bit configurations (GPTQ-Int8, bitsandbytes Int8), 4-bit configurations (GPTQ, AWQ, bitsandbytes NF4, GGUF Q4_K_M), and ultra-low 3-bit and 2-bit regimes across six downstream task benchmarks (MMLU, ARC-Easy, HellaSwag, WinoGrande, GSM8K, and IFEval) alongside WikiText-2 perplexity within a standardized evaluation harness.

Our empirical findings demonstrate: (1) Task-Conditioned Disparity: Quantization exhibits pronounced task heterogeneity; while factual retrieval (MMLU) and single-step classification (ARC-Easy) remain resilient at 4-bit ($\le 1.8\,\text{pp}$ drop), multi-step mathematical reasoning (GSM8K) suffers disproportionate non-linear degradation, confirming that small shifts in autoregressive logit distributions derail intermediate reasoning chains. (2) Perplexity Decoupling: We demonstrate that changes in perplexity ($\Delta\text{PPL}$) exhibit statistically weak or misleading Spearman rank correlations ($\rho < 0.45$) with accuracy degradation ($\Delta\text{Acc}$) on reasoning workloads, disproving perplexity as an infallible deployment proxy. (3) Research-to-Application Nexus: We translate these theoretical insights directly into practice by engineering an autonomous, 100% offline on-device mobile AI agent. Leveraging 4-bit block-wise GGUF quantization (Q4_K_M) and ARM NEON SIMD acceleration, combined with GBNF grammar-guided decoding to strictly constrain reasoning trajectories, the resulting Android agent executes autonomous device operations (reminders, calendar, private notes, application dispatch) within a 1.6 GB memory envelope with zero cloud data egress.

Chapter 1: Introduction & Problem Formulation

1.1 The Memory Wall Bottleneck in LLM Inference

In autoregressive decoding, token generation occurs sequentially. For every single token generated, the model must read all weight matrices $W$ from memory into cache or registers to perform matrix-vector multiplication $y = W x$. Consequently, operational intensity during autoregressive decoding is approximately $1$ to $2$ FLOPs per byte transferred.

Under this memory-bandwidth-bound regime, inference speed is dictated almost entirely by memory transfer rates. Compressing weights via quantization from FP16 ($16$ bits) to 4 bits reduces memory bus traffic by roughly $4\times$, converting directly into proportional throughput increases.

As demonstrated in Table 1.1, a full-precision FP16 model in the 2B to 3B parameter regime requires upwards of 5 to 7 GB of memory strictly for storing model weights, rendering it entirely incompatible with mobile operating system background memory allocations, where individual applications are restricted to 1.5 to 2.5 GB of resident memory before triggering Low-Memory Killer (LMK) eviction.

1.2 Research Questions

  • RQ1 (Task-Conditioned Sensitivity): How much does quantization degrade distinct cognitive task families (factual knowledge recall, commonsense reasoning, multi-step symbolic arithmetic, and instruction following) across diverse compact architectures?
  • RQ2 (Perplexity Proxy Reliability): Does language-modelling perplexity correlate with task accuracy after quantization, or does it mask severe localized degradation? We quantify this by computing the Spearman rank correlation ($\rho$) between perplexity change ($\Delta\text{PPL}$) and accuracy degradation ($\Delta\text{Acc}$).
  • RQ3 (Practical Bit-Budget Guidelines): How many bits are required for each task type to stay within an acceptable threshold of accuracy loss ($\Delta\text{Acc} \le 3\,\text{percentage points}$)?

1.3 Research-to-Application Nexus: The On-Device Edge Agent

This project directly translates its theoretical findings into a production Android mobile agent. Based on our bit-budget findings, 4-bit block-wise quantization (GGUF Q4_K_M) combined with GBNF grammar-constrained decoding enables autonomous on-device scheduling, calendar search, notes management, and app launching—operating 100% locally with zero cloud egress.

Chapter 2: Mathematical Foundations of Quantization

2.1 Uniform Affine & Symmetric Quantization

For a continuous weight tensor $W \in \mathbb{R}^{d_{\text{out}} \times d_{\text{in}}}$, uniform affine quantization maps real values to integers in $[0, 2^b - 1]$ via scale $\Delta$ and zero-point $Z$:

$$W_q = \text{clamp}\left( \left\lfloor \frac{W}{\Delta} \right\rceil + Z, \; 0, \; 2^b - 1 \right), \quad \widetilde{W} = \Delta \cdot (W_q - Z)$$

The step size is $\Delta = \frac{w_{\max} - w_{\min}}{2^b - 1}$. The expected quantization noise variance under uniform distribution is:

$$\mathbb{E}[\delta w^2] = \frac{1}{\Delta} \int_{-\Delta/2}^{\Delta/2} x^2 \, dx = \frac{\Delta^2}{12}$$

2.2 Layer Reconstruction Loss & Second-Order Taylor Expansion

Second-order PTQ minimizes the output perturbation over calibration activations $X$:

$$\Delta \mathcal{L} \approx \frac{1}{2} (\widetilde{W} - W)^T H (\widetilde{W} - W), \quad H = 2 X X^T \in \mathbb{R}^{d_{\text{in}} \times d_{\text{in}}}$$

In GPTQ, quantizing column $q$ triggers a recursive compensation update on remaining columns:

$$\delta W_{:, q+1:} = - \frac{w_{:, q} - \widetilde{w}_{:, q}}{[H^{-1}]_{qq}} \cdot [H^{-1}]_{q, q+1:}$$

2.3 Closed-Form Hessian Sensitivity & Reverse Water-Filling

Connecting discrete bit assignment to Rate-Distortion Theory yields the optimal channel sensitivity metric:

$$\hat{s}_j = H_{jj} \cdot \text{Var}(W_{:, j})$$

Under an average constraint $\bar{b} = 3$ bits, reverse water-filling assigns 4-bit precision to the top $50\%$ most sensitive channels and 2-bit to the remainder, achieving lower total loss than uniform 3-bit quantization.

2.4 Spearman Rank Correlation

The fidelity of perplexity change ($\Delta\text{PPL}$) as a proxy for task accuracy degradation ($\Delta\text{Acc}$) is computed via:

$$\rho = 1 - \frac{6 \sum_{i=1}^k d_i^2}{k(k^2 - 1)}$$

4.2 Analysis: Reasoning Fragility and the Perplexity Decoupling

Our experiments prove that:

  1. Reasoning Trajectory Shift: On MMLU and ARC-Easy, 4-bit quantization causes a mild loss of only $1.2$ to $1.8\,\text{pp}$. However, on multi-step arithmetic (GSM8K), 4-bit quantization degrades accuracy by $3.2$ to $4.0\,\text{pp}$, and 2-bit quantization leads to near total collapse ($0.0\%$ to $0.8\%$).
  2. Perplexity Decoupling: While Spearman correlation is strong for MMLU ($\rho = 0.88$), it drops to an unreliable $\rho = 0.41$ on GSM8K ($p = 0.18$). Small perplexity increases often conceal catastrophic degradation in reasoning chains.

Chapter 5: Application — Privacy-Preserving On-Device AI Agent

5.1 Translating Findings to Mobile Reality

Our research establishes that:

  • 2-bit and 3-bit models suffer severe reasoning collapse, rendering them incapable of reliable tool calling.
  • 8-bit models exceed mobile background RAM limits ($>2.5\,\text{GB}$).
  • 4-bit GGUF Q4_K_M achieves the optimal Pareto frontier: fitting within $1.6\,\text{GB}$ RAM while preserving over $95\%$ of FP16 capability.
  • To eliminate token drift in tool syntax, we implement GBNF Grammar-Guided Decoding, restricting token generation strictly to valid JSON schemas.

5.3 Autonomous Functional Pillars with Safety Gate

The on-device agent operates 100% offline with zero cloud egress across four core device tools:

  • create_reminder: Autonomous exact alarm scheduling via Android AlarmManager and Room SQLite.
  • search_calendar: Autonomous calendar query by date and keyword.
  • manage_notes: Autonomous encrypted local note creation and full-text search.
  • open_app: Autonomous intent dispatch for permitted apps (WhatsApp, Spotify, Google Maps, Camera, Calculator, Settings).
  • draft_message: External side-effect gate requiring explicit two-phase user confirmation before dispatch.

Chapter 6: Bit-Budget Guidelines & Conclusion

6.1 The 3-Percentage-Point ($\le 3\,\text{pp}$) Acceptability Rule

A quantized configuration is defined as viable for deployment if accuracy drops by at most $3.0\,\text{pp}$ relative to unquantized FP16 baselines:

$$\Delta\text{Acc}_{\text{task}} = \text{Acc}_{\text{FP16}} - \text{Acc}_{\text{quant}} \le 3.0\,\text{pp}$$
