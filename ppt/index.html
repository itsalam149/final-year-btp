Hardware Boundaries

The Edge Computing Challenge: Severe Mobile Limits

Mobile RAM & KV-Cache Ceiling

Modern smartphones feature 6GB to 8GB of total system RAM, but the Android OS strictly caps foreground applications to ≤ 3.5 GB.

FP16 Baseline LLM14+ GB RAM (Instant Crash)
Quantized 4-Bit Mobile SLM< 1.0 GB RAM (Safe)

Additionally, attention Key-Value (KV) cache memory expands with conversation turns, requiring aggressive context capping.

Thermal & Battery Envelope

Mobile processors cannot sustain continuous full-load inference without consequences:

  • Thermal Throttling: Sustained compute spikes device temperature, forcing mobile OS governors to throttle CPU clocks by 40–60%.
  • Battery Drain: Inefficient execution drains mobile battery rapidly. The assistant must execute tasks within low energy budgets (< 15 mAh per task).
  • ARM NEON Vectorization: Model weights must be quantized into INT4/INT8 formats optimized for mobile SIMD vector units.

Core Research Problem

The 4-Bit Syntax & Tool-Calling Collapse

The Perplexity Trap (Surface Fluency)

When Small Language Models (< 2B) are compressed to 4-bit, linguistic word perplexity on text corpora remains intact (~11–12 PPL). Practitioners falsely conclude quantization is lossless.

The Structural Syntax Cliff

When the same 4-bit model is asked to generate structured JSON function calls, syntax adherence collapses! The model outputs unclosed brackets, invalid parameter keys, and hallucinated functions.

Central Research Question

"How can quantization strategies preserve the reasoning and structured tool-calling capabilities required for reliable mobile task execution?"

A model that speaks fluently but generates invalid JSON tool calls is completely useless as an autonomous mobile agent. Our project solves this through Grammar-Constrained Decoding.

Quantization Hierarchy & The GGUF Runtime

Benchmarking precision formats for on-device ARM NEON execution:

Quantization Precision Model Size (1B Params) RAM Required Inference Latency Mobile Deployment Verdict

Slide 7 / 13Quantization & GGUF Pipeline
Technical Innovation

Grammar-Constrained Decoding (BNF Grammars)

MATHEMATICAL GUARANTEE

The Finite-State Token Masker

Instead of letting the 4-bit model freely sample tokens that might hallucinate invalid syntax:

  • We author a Backus-Naur Form (GBNF) grammar defining valid JSON tool calls.
  • At every step of autoregressive generation, llama.cpp evaluates the grammar state.
  • Logit Masking: Tokens that violate the schema receive logit = -∞, making invalid syntax mathematically impossible.
  • Result: 100% syntactically valid tool calls on 4-bit models with zero parsing exceptions!
// GBNF Grammar Sample
root ::= "{" ws ""type":" ws (action | message) ws "}"

action ::= ""action", "thought":" string ", "tool":" tool_name ", "parameters":" params

tool_name ::= ""create_reminder"" | ""search_calendar"" | ""manage_notes"" | ""search_local_docs""

params ::= reminder_params | notes_params | ...

Security & Safety

Zero Cloud Egress & Security Architecture

Zero Internet Permission

The Android Manifest strictly omits android.permission.INTERNET. The OS kernel physically prevents the app from creating network sockets, mathematically guaranteeing zero data leaks.

Human-in-the-Loop Confirmation

Consequential or communication tools (e.g. drafting messages) are intercepted by the confirmation gate, requiring explicit user touch before invoking Android intents.

Prompt Injection Defense

Text retrieved from untrusted local documents is wrapped in strict delimiters (<untrusted_document_context>) with prompt rules preventing override of agent security policies.

Complete Local Audit Log

Every tool invocation, timestamp, parameter payload, and authorization status is logged into a secure SQLite table for full user transparency.

Empirical Methodology

Agent-Aware Quantization Benchmark (AAQB)

Evaluating mobile agents requires metrics beyond simple text perplexity:

SYNTAX RIGOR

Syntax Adherence ($Acc_{syn}$)

Percentage of model generations that parse as 100% valid JSON without structural formatting exceptions.

TOOL ACCURACY

Tool Identification ($Acc_{id}$)

Accuracy in routing natural-language instructions to the correct tool among the available mobile toolset.

TASK SUCCESS

End-to-End Success ($Acc_{e2e}$)

Full execution success rate verifying that the reminder, note, or search was completed accurately on device.

Hardware Profiling Metrics: Time-to-First-Token (TTFT in ms), Generation Speed (tokens/sec), Peak RSS Memory (MB), and Energy Consumption (mAh per task measured via Android BatteryManager).
